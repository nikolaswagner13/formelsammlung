# Technische Formelsammlung mit Wissensbereich

## Upload
Alle Dateien und den Ordner `assets` in das Stammverzeichnis des GitHub-Repositorys hochladen. Vorhandene Dateien ersetzen. GitHub Pages bleibt auf `main` und `/ (root)`.

## Eigenes Bild ergänzen
1. Im Repository `Add file` > `Create new file` wählen.
2. Als Pfad `assets/sprint-planning.png` verwenden oder den Ordner lokal anlegen.
3. Das gewünschte Bild genau als `sprint-planning.png` hochladen.
4. Nach dem Deployment ersetzt die Seite automatisch den Platzhalter.

Für JPG oder WebP den Pfad in `wissen.js` bei `assets/sprint-planning.png` ändern.

## Inhalte
- `formeln.js`: Formeldaten
- `wissen.js`: Scrum, Kanban, Refinement und PI Planning
- `styles.css`: vollständiges Design
- `script.js`: Suche, Filter, Tabs, Dark Mode und MathJax

Hinweis: GitHub Pages ist öffentlich. Keine vertraulichen Unternehmensinformationen veröffentlichen.
